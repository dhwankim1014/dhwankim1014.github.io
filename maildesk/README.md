# Maildesk — AI 메일 분류 · 회신 초안 · 할 일 관리 (검토형 업무 보조)

거래처 메일을 **업무 유형별로 분류**하고, 요청사항·품번·수량·기한을 뽑아 **할 일 목록**을 만들고,
**회신 초안 3종**을 제안합니다. **AI는 메일을 보내거나 지우지 않습니다.** 최종 판단과 발송은 담당자가 합니다.

> 모든 메일·회사·인물은 가상입니다. 실제 학교/회사 메일은 읽지 않으며, Outlook의 `Maildesk-테스트` 폴더만 사용합니다.

## 지금 상태 (2026-11-19)

| 기능 | 상태 | 확인한 방법 |

| 사람 단독 vs 보조 처리시간 측정 | 실험 설계·기록지 준비 | 실험 필요 |

## 현재 수치 (주의해서 읽기)

가상 메일 30건, 정답표 v1(사용자 검토 전) 기준:

| 항목 | 규칙 | AI |
|---|---|---|
| 1차 분류 | 87% | 100% |
| 2차 분류 | 80% | 100% |
| 기한 | 87% | 97% |
| 품번·수량 | 87% | 100% |
| 회신 필요 메일 놓침 | 1/19 | 0/19 |

**메일·정답표·규칙·AI가 모두 Claude에서 나왔기 때문에 이 숫자는 부풀려졌을 수 있습니다.**
포트폴리오에는 [eval_kit/측정_실험_설계.md](eval_kit/측정_실험_설계.md)의 실험으로 다시 잰 숫자만 씁니다.

## 실행 방법 (PowerShell, `maildesk` 폴더의 상위에서)

```
python maildesk/connect/outlook_check.py                    # 1. 테스트 폴더 연결 확인
python maildesk/connect/seed_test_folder.py --all           # 2. 가상 메일 넣기 (중복은 건너뜀)
python maildesk/run_eval.py                                 # 3a. 규칙 분류 + 채점
python maildesk/run_eval.py --classifier cli                # 3b. AI 분류 + 채점 (구독 사용)
python maildesk/compare.py rule-v1 cli-v1-medium            # 4. 비교 보고서
python maildesk/run_drafts.py                               # 5. 회신 초안 3종
python maildesk/build_tasks.py                              # 6. 할 일 목록 + 엑셀 업무 대장
python maildesk/build_app.py                                # 7. 검토 화면 → app/maildesk.html 더블클릭
python maildesk/connect/outlook_apply.py                    # 8. Outlook 태그·깃발 미리보기 (--apply / --undo)
```

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `data/` | 가상 메일 30건 + 정답표 (JSON, 엑셀) |
| `connect/` | Outlook 연결·읽기·메일 넣기·태그 반영 |
| `classify/` | 규칙 분류기, AI 분류기(API/CLI), 회신 초안 |
| `results/` | 채점 보고서, 비교 보고서, 초안, 할 일, 업무 대장 |
| `app/` | 검토 화면 (`maildesk.html` 한 파일, 인터넷 없이 열림) |
| `eval_kit/` | 새 테스트 메일 양식, 시간 측정 기록지, 실험 설계 |
| `tools/` | 엑셀 변환·양식 생성 |

## 안전 장치

- 읽기: `Maildesk-테스트` 폴더 하나만. 다른 폴더의 메일은 열지 않음.
- 쓰기: 메일 발송·삭제·이동 기능 없음. 태그·깃발 반영은 테스트 폴더에만, 기본은 미리보기.
- AI: 정답 예시를 보여주지 않음. 도구를 모두 끈 빈 폴더에서 실행. 판단 근거 문장·품번을 본문과 코드로 대조.
- 회신 초안: 단가·가능 여부·출하일 등 미확정 정보는 `[확인 필요: …]` 빈칸. 원문에 없는 숫자는 경고.
- 검토 화면: 사람이 고친 내용을 기록 → 수정률 측정. 기록은 그 브라우저에만 저장.

## 알려진 한계

- 정답표 v1은 아직 사람 검토 전. 특히 M13의 기한(적용일 vs 회신 기한) 기준이 모호함.
- 규칙 분류기의 알려진 버그(‘이번 주간’을 ‘이번 주’로 인식)는 기준선 보존을 위해 그대로 둠.
- 가상 메일 넣기에서 발견·해결한 문제: ① 첫 저장 전에 메시지 플래그를 지정하지 않으면 '미발송 초안'으로 저장돼 깃발이 거부됨
  ② 안 읽음 표시를 첫 저장 전에 하면 미발송 플래그가 되살아남 ③ pywin32 날짜 변환 때문에 기한이 하루, 받은 시각이 9시간 밀림 → 정오·UTC 숫자로 전달.
- 클래식 Outlook이 켜져 있어야 동작 (새 Outlook은 미지원). 학교 계정은 졸업 후 사라질 수 있어 JSON 모드도 지원.
- 알림 규칙(24시간, 1영업일)은 가정. 실제 업무 규정에 맞춰야 함.
