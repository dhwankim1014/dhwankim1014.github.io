# 김동환 · AI 활용 포트폴리오

AI로 반복 업무를 더 정확하고 빠르게 만드는 실무형 지원자의 포트폴리오 저장소입니다.

- **포트폴리오 사이트**: https://dhwankim1014.github.io
- **Maildesk 데모**: https://dhwankim1014.github.io/maildesk/app/maildesk.html

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 포트폴리오 사이트 (소개 · AI 학습 이력 · 프로젝트) |

## 프로젝트

### Maildesk — 구현 완료 · 효과 실측 중
거래처 메일을 업무 유형별로 분류하고 요청사항·품번·기한을 뽑아 할 일과 회신 초안까지 만들어 주되,
발송과 최종 판단은 담당자가 하는 검토형 업무 보조 시스템입니다. 자세한 내용은 [maildesk/README.md](maildesk/README.md).
